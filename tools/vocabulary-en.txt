# Slownik akceptacji jezykowej — tools/check-english.js
#
# Kazda linia to ODPOWIEDZ CZLOWIEKA na jedno pytanie: "czy to slowo nalezy do
# angielskiego interfejsu tych narzedzi". Nie jest to lista dopuszczonych napisow
# ani lista wyjatkow — to zapis przegladu, ktory ktos wykonal i ktory da sie
# powtorzyc, bo lezy w repozytorium, a nie w czyjejs pamieci.
#
# DLACZEGO SLOWA, A NIE NAPISY. Napisow sa tysiace i przybywa ich z kazdym
# komunikatem; slow jest tysiac i przybywa kilka na zmiane. Poprzednie kryterium
# pytalo o napisy przez liste slow funkcyjnych i przepuscilo trzynascie pozycji
# polskiego tekstu, raportujac na nich zero (#63).
#
# JAK SIE UZUPELNIA. Recznie. check-english.js wypisuje przy porazce gotowy blok
# slow do przeczytania — przeczytaj kazde i dopisz tutaj te angielskie, a polskie
# przetlumacz w zrodle. Nie ma flagi --update i nie ma jej miec: brama przegladu
# z przyciskiem "zaakceptuj wszystko" nie jest brama przegladu, a odruchowe --update
# na czerwonym diffie jest awaria, ktora to repozytorium juz zaplacilo siedmioma
# czerwonymi fixturami przyjetymi jako nowe wyjscie (docs/PRINCIPLES.md).
#
# JEDYNY SPOSOB, W JAKI TEN STRAZNIK MOZE ZAWIESC, to dopisanie tutaj slowa, ktore
# nie jest angielskie. Nic innego go nie omija — i dlatego kazda taka linia jest
# decyzja, a nie porzadkami.
#
# CO TU JEST: slowa angielskie, nazwy wlasne (wydania OpenStacka, dystrybucje),
# skroty techniczne oraz czlony identyfikatorow rozciete na granicy liter
# (network_interface -> network, interface).
#
# CZEGO TU NIE MA I DLACZEGO: nazw znacznikow (code, span, strong), nazw encji
# (ldquo, rarr, quot) ani nazw wstawek ({releaseTo} -> releaseto). Zadne z nich
# nie jest slowem, ktore uzytkownik czyta; wpadly do pierwszego pomiaru i zostaly
# odciete w check-english.js, a nie przyjete tutaj. Przyjecie artefaktu pomiaru
# do zbioru zaakceptowanego zapisuje wade pomiaru jako fakt o produkcie.
